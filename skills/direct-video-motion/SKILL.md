# Video Motion Direction

1. Turn the approved script into a table of beat duration, exact copy, narration, focal element, motion cue, source asset and license. Name the intended aspect ratio and language so the first storyboard is already usable.
2. Begin an explainer with a question, introduce the mechanism in distinct chapters, and close by resolving the question. Derive chapter markers from real scene starts. For a product launch, carry a focal object or motion direction across the handoff and hold the end card long enough to read the CTA.
3. Give each beat one dominant movement. Use orientation or scale changes only when they clarify what is happening. Keep a data chart's scale stable, and show the units, source and as-of date on camera.
4. Use the official Remotion guidance for React compositions, GSAP guidance for seekable HTML timelines and LottieFiles motion principles for timing and choreography. In PipelineX, use `renderer/templates/README.md` for setup and the local HyperFrames review path. Apply the current job's visual identity and use reference examples for principles with original layouts and assets.
5. Compare captions to approved narration. If the voice step lacks word marks, use an approved per-beat WhisperX alignment with the PipelineX importer, then listen across beat transitions. Keep printed numbers, names and units from the approved script.
6. Review the hook, first transition, most crowded frame and last hold at target size. Report the storyboard, files, and observed timing or legibility issues.
