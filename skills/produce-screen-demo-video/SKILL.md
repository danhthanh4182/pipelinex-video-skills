# Produce Screen Demo Video

1. List the visible user actions and the outcome that proves the feature. Choose one window, use demo data and leave room for captions. Hide notifications and any private information before capture.
2. When OpenScreen is available, capture local audio and video as required. Use cursor smoothing and targeted zooms to reveal the action. Leave enough time before a click to locate the target, and hold the completed state so the viewer sees the result.
3. For supplied recordings, probe the source and inspect the first frame, action peaks and ending. Spot labels, watermarks, browser overlays and private details. Preserve attribution. Keep editorial cuts and adjustments in a separate project.
4. Trim dead time, add narration or captions where useful and check that zooms and crops preserve UI context and Vietnamese text. For a 9:16 cut, reframe around the active region and review the subtitle safe area.
5. Deliver the source, edit decision list and reviewed export when requested. In PipelineX, attach an approved recording as local footage. Use FFmpeg to verify the expected geometry, duration and audio streams.
